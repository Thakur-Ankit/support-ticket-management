# Review Code

Review the current implementation against:

1. The applicable specification.
2. The implementation plan.
3. The task list.
4. Project constitution.
5. Java/Spring Boot guidelines.
6. API standards.
7. Testing guidelines.

Check for:

- correctness
- missing requirements
- bugs
- invalid state transitions
- validation gaps
- error handling
- security problems
- duplicated logic
- unnecessary complexity
- poor naming
- missing tests
- specification drift

Do not modify code during the first review.

Produce:

## Findings

List each issue with:
- severity
- file
- location
- problem
- expected behavior
- recommended fix

## Positive Findings

List important things implemented correctly.

## Specification Gaps

Identify requirements that are not implemented.
