# Review Specification

Review the specification and all related design artifacts.

Check:

- requirements are testable
- acceptance criteria are measurable
- no contradictory requirements exist
- state machine is completely defined
- API behavior is defined
- validation behavior is defined
- error behavior is defined
- persistence requirements are defined
- UI behavior is defined
- testing expectations are defined

Do not modify artifacts.

Report:

1. Missing requirements
2. Ambiguous requirements
3. Contradictions
4. Missing acceptance criteria
5. State-machine gaps
6. API gaps
7. Testing gaps
