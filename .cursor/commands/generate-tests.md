# Generate Tests

Read the applicable specification and implementation.

Identify behavior that lacks automated tests.

Prioritize:

1. State-machine rules
2. Validation
3. API behavior
4. Persistence
5. Search
6. Filtering
7. Comments
8. Error handling

Before writing tests:

- identify the requirement being tested
- identify the expected behavior
- identify existing test coverage

Generate focused tests.

Do not change production code unless explicitly requested.

After generating tests, explain which requirements each test covers.
